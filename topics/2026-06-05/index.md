## Talk 2 June 5

We will work through some demos for making our own Icechunk stores.

* [Tutorial 1](virtualizarr_ndvi_cdr_concat.html): Create a local icechunk store by creating a multi-file virtual dataset.
* [Tutorial 2](virtualizarr_ndvi_cdr_append.html): Create a local icechunk store by appending to an icechunk store.
* [Tutorial 3](virtualizarr_ndvi_cdr_kerchunk.html): Create a local icechunk store by creating kerchunk json.
* [Tutorial 4](virtualizarr_ndvi_cdr_append-cloud.html): Create a icechunk store on cloud storage.
